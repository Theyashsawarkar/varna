Changelog

Every change to varna, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

v0.1.52026-10-21release ↗

  • Rosé Pine and Dawn colour tmux's dev servers capsule rose, so it no longer matches the green of a status capsule (their green, teal and sky are all foam).

v0.1.42026-10-21release ↗

  • tmux gets more colours from the theme: @attention (peach: something waits for you), @dev (sky: dev servers) and @ok / @warn / @error (status capsules that go green, yellow, red).

v0.1.32026-10-21release ↗

  • Rosé Pine's and Dawn's second accent is foam (their cyan) instead of rosewater, which sat too close to iris: the current tmux window, the active pane, popups, the prompt's folder and fzf's highlights.

v0.1.22026-10-21release ↗

  • Vayu's second accent is pink (#f5c2e7, Catppuccin's pairing with its mauve) instead of the dusty rose left over from the old tmux palette: the current tmux window, the active pane, popups, menus, the prompt's folder and fzf's highlights.

v0.1.12026-10-21release ↗

  • The focused window's border is the theme's accent in every theme (Vayu used red, Rosé Pine and Dawn their rose), so it matches the active workspace, the tmux session and the rest of the highlights.

v0.1.02026-10-21release ↗

The first release: one theme for every tool.

  • Themes are TOML files: a 26-colour palette (Catppuccin's names), roles (accent, second accent, border, urgent, ink...), ui values (fonts, radius, opacity, gaps, border width) and optional per-tool extras. Ten shipped: Vayu, Catppuccin Mocha / Latte, Rosé Pine / Dawn, Tokyo Night, Gruvbox, Nord, Kanagawa, Everforest.
  • Twelve tools: sway, waybar, tmux, kitty, mako, Vyom, Neovim, powerlevel10k, fzf, lazygit, swaylock and GTK apps (opt-in), plus palette.json for any program. Each tool includes one generated file; varna apply writes them all and reloads what's running (every tmux server, kitty window and Neovim, sway, waybar, mako, Vyom).
  • Per-tool themes (varna tool nvim tokyo-night), accent override (varna set accent blue), light/dark twins (varna mode toggle), and the desktop's dark/light signal for apps that follow it.
  • Your own themes (varna new, varna edit, varna delete) and any file as a template (varna template add), with filters (:a=0.35, :rgb, :alpha=0.4, :mix=), fallbacks ({{a|b}}) and line conditions (?swayfx). Unknown names are errors.
  • varna doctor checks every theme and prints the line each tool's config is missing; varna ensure writes missing files at login so waybar and mako always start; a throwaway HOME never reloads the running desktop.
